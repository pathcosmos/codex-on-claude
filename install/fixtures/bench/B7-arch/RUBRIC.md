# B7 — architecture Q&A rubric

| Criterion | Pass | Notes |
|---|---|---|
| `layer` field is one of the 4 valid enum values | mechanical | Forces a commitment. |
| At least 2 files cited in `files_cited` | mechanical | Discourages handwaving. |
| `tradeoff` paragraph present | mechanical | Records what's given up by choosing this layer. |
| Total prose ≤ ~300 words (380 cap incl. JSON) | mechanical (word_count_max) | Discourages essay-padding. |

Quality assessment of the *content* (does the recommendation make sense?) is intentionally human, not mechanical. The mechanical rubric only checks that the answer is well-structured.
