# Stack module spec

Create a `Stack` class (in `stack.js`) with these methods:

- `push(item)` — appends item to top
- `pop()` — removes and returns top item; returns `undefined` if empty
- `peek()` — returns top item without removing; returns `undefined` if empty
- `size()` — returns number of items
- `clear()` — removes all items
- `isEmpty()` — returns `true` if empty

Export as CommonJS: `module.exports = { Stack };`
